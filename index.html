Endpoints

      
Cada ruta lleva la institución de origen en el segundo segmento, así sabes de dónde viene el dato sin abrir la documentación. Todo responde JSON sobre HTTPS y sin SDK: si tu lenguaje sabe hacer una petición, ya puedes usarla.

    

    
    
      
  • GET/v1/jce/cedula/{cedula}Valida una cédula y devuelve el nombre registrado.
    • 
      
  • GET/v1/dgii/rnc/{rnc}Consulta un RNC en el registro de la DGII.
    • 
      
  • GET/v1/one/provinciasLas 32 provincias con su código, región y municipio cabecera.
    • 
      
  • GET/v1/mt/feriados/2026Feriados nacionales del año, con la fecha ya trasladada.
    • 
      
  • GET/v1/bcrd/tasa-cambioTasa de compra y venta del Banco Central, del día.
    • 
      
  • GET/v1/inposdom/codigo-postal/{codigo}Resuelve un código postal a municipio y provincia.
    • 
    

  






  

    

      
De dónde salen los datos

      
Cada endpoint tiene una fuente oficial detrás. Consolidamos, normalizamos y servimos:
         tú no tienes que pelear con seis portales distintos.

Términos de uso

      
Resumen en lenguaje claro. El documento completo está en la documentación.

    

    

      

        
Datos públicos

        
La API expone información que ya es de acceso público. No almacenamos consultas
           asociadas a tu API key más allá de lo necesario para contar el uso.

      

      

        
Uso responsable

        
Está prohibido usar la API para perfilar personas, revender los datos o
           reconstruir bases completas. Una API key que lo haga se revoca sin aviso.

      

      

        
Sin garantía

        
Los datos vienen de fuentes oficiales y pueden estar desactualizados.
           El plan gratuito se ofrece tal cual; para garantías existe el plan a medida.
